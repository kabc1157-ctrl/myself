# 일기·루틴 AI 인사이트 연결 흐름

현재 화면은 AI 결과가 들어올 자리를 먼저 제공하고, 실제 외부 호출은 자격 증명을 준비한 뒤 연결한다.

1. 사용자가 일기 또는 루틴 회고를 저장한다.
2. 웹 서버는 Supabase에 원본 기록을 먼저 확정한다.
3. 서버 전용 환경 변수로 보호한 n8n Webhook에 `userId`, `recordType`, `recordId`만 전달한다.
4. n8n은 Supabase의 서버 전용 자격 증명으로 해당 사용자의 원본 기록과 당일 통계를 읽는다.
5. AI는 구조화된 결과(핵심 피드백, 잘한 점, 개선할 점, 내일 행동 한 가지)를 생성한다.
6. n8n은 결과와 분석 시각을 Supabase에 저장한다.
7. 앱은 저장된 결과만 조회해 `AI INSIGHT` 카드에 표시한다.

재시도 중 중복 분석을 막기 위해 `recordType + recordId + promptVersion`을 멱등 키로 사용한다. Webhook URL과 AI·Supabase 비밀키는 브라우저에 노출하지 않고 n8n 및 서버 환경 변수에만 둔다. 월간 분석은 같은 저장소를 사용하되 n8n 예약 워크플로로 별도 실행한다.
